## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Gallery** | Organize Procreate illustrations with client and status tags |
| **Brush Library** | Track brush sets with style category and source information |
| **Commission Tracker** | Log commission queue from inquiry through to final delivery |
| **Canvas Notes** | Document canvas size and color profile settings per project type |
